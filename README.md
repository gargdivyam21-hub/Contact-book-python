# 📒 Contact Book App (Python)

A simple command-line contact manager built using Python.

---

## 🚀 Features

* Add contact
* View contacts
* Search contacts (case-insensitive & partial match)
* Delete contact
* Phone number validation (10 digits)

---

## 🛠️ Tech Used

* Python

---

## ▶️ How to Run

```bash
python main.py
```
