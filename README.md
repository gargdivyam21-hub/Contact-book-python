# 📱 Contact Book - Python

A simple and user-friendly **Contact Book application built with Python**.

This project allows users to add, view, search, update, and delete contacts. Contact data is stored in a JSON file so that it remains available even after the program is closed.

## ✨ Features

- ➕ Add new contacts
- 📋 View all contacts
- 🔍 Search contacts by name
- ✏️ Update contact name or phone number
- 🗑️ Delete contacts with confirmation
- 📱 Validate 10-digit phone numbers
- 🚫 Prevent duplicate names
- 🚫 Prevent duplicate phone numbers
- 💾 Store contacts permanently using JSON
- ⚠️ Handle invalid input
- 🔤 Case-insensitive search

## 🛠️ Technologies Used

- Python 3
- JSON
- File Handling
- Functions
- Dictionary
- Conditional Statements
- Loops
